# Cover images

Drop a book's cover here named after its **slug**, e.g. `chirurg.jpg`, `hail-mary.jpg`,
`dziki-mroczny-brzeg.png`. Supported: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

The slug is derived from the title (lowercase, Polish letters simplified, spaces → `-`).
If a matching file exists it is optimized and shown automatically on the next build;
otherwise a neat placeholder is used. No code changes needed.
